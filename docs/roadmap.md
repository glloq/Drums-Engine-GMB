# Roadmap technique

## Phase 1 — Consolidation cœur runtime
- Stabiliser scheduler/queue/watchdog.
- Standardiser bench latence/jitter.
- Vérifier robustesse sous charge multi-actionneurs.

## Phase 2 — Pipeline & Event Engine
- Étendre les blocs V1 réellement supportés.
- Finaliser UI -> pipeline compilé.
- Ajouter tests de scénarios instrument complexes.

## Phase 3 — API/Web & exploitation
- Durcir validation API.
- Exposer davantage de métriques runtime.
- Documenter troubleshooting et procédures terrain.

## Phase 4 — Extension plateforme
- Préparer portabilité ESP-IDF natif.
- Étudier backend Linux RT.
- Clarifier abstraction hardware et timing.

## Phase 5 — Industrialisation
- Tests automatiques (unitaires/intégration).
- Versioning des configurations.
- Documentation contributeur complète.
