# UI V1 (structure cible)

## Onglets
- Actuators
- Instruments
- Mappings
- System

## Objectif UI
- Édition simple et rapide.
- Correspondance claire entre UI et pipeline moteur.
- Supervision minimale des états runtime.

## Parcours de configuration
1. Créer les actionneurs.
2. Créer les instruments.
3. Associer notes MIDI et comportements.
4. Tester instrument/actionneur.
5. Sauvegarder la configuration.

## Améliorations UI à prévoir
- Éditeur pipeline visuel complet (blocs chaînés).
- Feedback temps réel (latence/jitter visibles).
- Validation stricte des formulaires côté client.
